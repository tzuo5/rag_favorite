# 小红书关注博主 ingestion 调研与实施决策

调研与验证日期：2026-10-06。实际项目为 `/home/tzuo5/gpt projects/rag_favorite`。

## 平台入口与证据

已用当前账号验证主页展示精确关注数 40；页面正常加载的
`GET /api/im/web/users/following/all` 返回 40 个唯一用户 ID。当前实现只在
`follow_user_d_t_o_list` 去重数量与主页精确计数相同时认定名单完整。
该接口不是官方公开 API，接口名带 `all` 也不能单独作为完整性保证。
精确计数缺失、列表数量不符、登录失效、平台限流或页面变化均明确停止。

作者发布内容使用签名 `GET /api/sns/web/v1/user_posted`。真实多页作者验证
首批 31 项、下一批 30 项，`has_more=true` 且游标前进；不采用首页 HTML
作为历史全量结果。首次限页导入已读取两页、提交 62 个不同任务。

参考资料：

- [MediaCrawler 作者分页源码](https://github.com/NanmiCoder/MediaCrawler/blob/main/media_platform/xhs/client.py)：包含分页方法及数量上限，不能直接等同于无上限全量回填。
- [MediaCrawler 许可证](https://github.com/NanmiCoder/MediaCrawler/blob/main/LICENSE)：非商业学习用途及采集规模限制；本实现未引入其完整代码。
- [xhs-cli 客户端源码](https://github.com/jackwener/xhs-cli/blob/main/xhs_cli/client.py)：following 读取页面状态；用户发布内容方法只读首页，不能直接承担本需求的完整性验收。
- [XHS-Downloader](https://github.com/JoeanAmier/XHS-Downloader)：媒体与页面链接采集参考；没有把其工具说明当成本账号全量关注采集已验证。

## 全部默认假设

| 项目 | 采用的假设或默认 |
| --- | --- |
| 账号与用户 | 单用户、单账号；共享已有私有 Cookie、浏览器与永久账号绑定 |
| 作者范围 | 本账号关注的所有博主；不用白名单、热度或主题筛选 |
| 内容范围 | 作者发布、当前账号可正常访问的视频和图文；不含作者收藏、点赞、评论、私信和直播 |
| “全部” | 平台当前可枚举且可访问的内容；不保证已删、私密、封禁或平台未返回的内容 |
| 历史范围 | 无时间和内容数量截断；运行时长与队列容量仅导致暂停续扫 |
| 持续同步 | 新关注作者自动回填；历史回填期间每日独立检查作者首页，保留历史游标 |
| 取关 | 仅完整关注快照能确认移除；停止发现，保留已入库内容和已入队任务 |
| 更新 | 不自动重做已完成内容；旧版 `text_only` 图文升级一次图片处理；周期重扫补漏 |
| 存储 | `collection=all` 对应当前默认分区；旧 cooking key 不限制主题 |
| 视频 | 使用现有字幕、ASR、视觉开关、模型、预算、ImageBind、检查点和清理流程 |
| 图文 | 所有图片下载与本地 RapidOCR；视觉启用时逐图 VLM；不伪造视频时间戳 |
| 图片证据 | 保留完整图片顺序、OCR 框、置信度、SHA256、原图证据；VLM 使用缩小的单独副本 |
| Live Photo | 可获取的视频进入同一视频队列；不可获取时明确记录动态媒体缺口 |
| 原始媒体 | 不建立永久原视频档案；沿用清理策略，保留必要图片证据、正文和知识 |
| 基础设施 | 现有 Linux、PostgreSQL、Playwright、xhshow、systemd；不新增商业采集服务 |
| 调度 | 每日 07:15、18:15 America/Chicago；未完成任务每半小时续跑 |
| 限速 | 签名请求与媒体页读取共享至少 3 秒的账号请求起始间隔；浏览器产生的附属请求不声称逐个受该限速器控制 |
| 资源 | 单采集进程、现有单 worker；每次默认最多 30 分钟 |
| 背压 | queued/running 达到 500 暂停，降至 250 后恢复；保留剩余内容 |
| 增量终止 | 连续三页已知笔记结束近期检查；约每七日进行完整重扫，不把增量当历史全量证明 |
| 临时网络失败 | 最多三次请求，递增等待；验证码、429 和结构变化明确暂停 |
| 入口 | CLI、JSON 状态及后台服务；本版不新增 GUI、Telegram 或 MCP 写入入口 |

## 实施边界

关注名单的精确计数验证已在当前账号通过，但不代表所有账号或未来平台版本都能工作。
名单不匹配时不会改用推荐 feed、搜索结果或猜测名单。所有分页游标、作者状态与来源
关联写入核心数据库；收藏、关注和手动入口同库同分区去重并保留不同来源。

图片的 OCR、视觉描述进入既有 Markdown 文本检索；图文没有视频时间轴。本版没有
新增独立的 ImageBind 图片相似检索通道，现有 ImageBind 视频检索仍按原流程工作。
预算、登录或媒体失败会保留实际未完成状态，不因列表已经入队就宣称处理全部成功。
