## CCR 本机补丁

`scripts/repair_ccr_stream.py` 只在唯一匹配的 CCR 流桥上打补丁，并保存带原文件
SHA-256 的备份；找不到唯一匹配时拒绝修改。此次修改的是本机 CCR 3.1.1 的
`dist/main/cli.js`。没有修改模型 ID、medium 推理配置或供应商路由。

安装或升级 CCR 可能覆盖这个本机补丁。升级后运行
`scripts/check_ccr_stream.py`，确认上游断流及时结束下游；如果失败，先核对版本和
桥接实现，再运行受保护的修复脚本。该检查使用隔离实例及本地模拟上游。
