# 桌面 GUI 实施与验收

验收时间：2026-10-04 15:39，America/Chicago。队列持续运行，以下数量仅为当时快照。

已部署独立 Qt 桌面窗口，并安装桌面 `RAG任务控制台.desktop` 与应用菜单入口。
真实窗口截图已保存到桌面 `RAG-GUI-实际界面.png`。

## 已实现

- 直接读取当前所有者知识库的 PostgreSQL 队列，每 3 秒刷新。
- 显示任务顺序、标题、阶段、模型、状态、当前阶段进度、更新时间与尝试次数。
- 按状态和存储分类筛选，搜索标题 / ID / 错误码，查看选中任务详情。
- 自动读取 CCR、Faster Whisper、LM Studio Embedding、ImageBind 配置。
- 整体 Start / Stop、单任务暂停 / 恢复、失败与受阻任务的显式重试。
- 文件锁协调暂停与数据库领取事务，原子保存暂停状态。
- 当前 worker PID 的控制能力核验，以及 GUI 单实例窗口唤起。
- 后台读取与操作，数据库断连提示与自动重连，结构化任务日志。

## 输入与范围

需要已配置的主 TOML、视频 TOML、PostgreSQL，以及已安装的用户 worker 服务。
GUI 不展示认证信息或签名来源 URL。

模型“处理中”依据当前任务阶段；端口在线不代表认证或模型推理已经验证。
本地文本 Embedding 额外读取模型清单，区分“已加载”和“未加载”。
当前阶段的帧数 / 音频片段数不是整个任务的百分比。
Stop 的含义是暂停后续领取，正在执行的任务继续结束；它不取消任务。
最多显示前 2000 个任务，汇总数量仍从全部任务计算。

使用方法与卸载见[桌面任务控制台](../desktop-gui.md)。
本机原始验收记录保存于 `.runtime/gui/acceptance.json`，截图及启动日志也保存在该目录。
